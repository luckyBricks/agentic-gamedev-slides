# Rider for Agentic GameDev｜Notion & Slidev Markdown Pack

这是一套按页拆分的 Markdown 提示词包，适合两种用法：

1. 作为 Slidev 制作提纲：逐页打开 `.md` 文件，把其中的标题、文案骨架、图像提示词、Mermaid 草图改成正式页内容。
2. 作为 Notion 子页面素材：把整包导入 Notion，在页面内形成一组按顺序组织的子页面，再逐页细化。

## 推荐使用方式

### 在 Slidev 中使用
- 每个页面文件都包含：页面目标、视觉主图提示词、信息图提示词、文案提示词、一个可直接改写的 Slidev 草图，以及讲者备注。
- 建议先按 01–22 完成正文，再视听众加入 23–26 附录页。
